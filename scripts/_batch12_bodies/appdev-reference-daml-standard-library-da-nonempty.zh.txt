# DA.NonEmpty

非空列表的类型与函数。本模块再导出许多与 Prelude 列表同名的函数，建议 **qualified import**。

例如下列 import 可得 `NonEmpty` 类型，非空列表函数以限定名使用，如 `NE.append`、`NE.map`、`NE.foldl`：

```

import DA.NonEmpty (NonEmpty)

import qualified DA.NonEmpty as NE

```
