# 验证者活跃度

> 验证者活跃度奖励与相关代币经济学。

在每一轮中，每个实时验证者都会使用 验证者活跃度ActivityRecord 记录其活跃活动。这会奖励验证者可以验证和确认交易。它还为他们提供初始资金，用于在入职后购买额外流量以获得更高的吞吐量。
