## 文档结构

本文档分为四个部分：

* **概述**：Canton 概念、架构和协议 — 适合所有人
* **应用程序开发**：使用 Daml 和 API 构建应用程序 — 面向开发人员
* **全局同步器**：操作验证器和基础设施 - 针对运营商
* **构建块**：钱包、应用程序、组件和集成 - 面向开发人员和用户

在每个部分中，内容遵循渐进的深度模型：

* **理解**：每个人的概念基础
* **学习**：更详细的理解和实际应用
* **参考**：深层协议机制和 API 文档

## 先决条件

在投入之前，您应该：

* **对于开发人员**：任何语言的编程经验。熟悉函数式编程概念会有所帮助，但不是必需的。
* **对于操作员**：具有容器化部署（Docker、Kubernetes）和基本网络概念的经验。
* **适合所有人**：无需具备区块链经验。我们从第一原理解释概念。
