> 发现基于 Canton Network 构建的应用

Canton Network 生态正在不断增长，涵盖多个类别的应用。

## 浏览生态

Canton Network 应用的主目录维护在 [canton.network/ecosystem](https://www.canton.network/ecosystem)。你可以在那里浏览精选应用、生态合作伙伴，并发现基于 Canton 构建的项目。
